# Скилл: Фиксация Результатов (Заготовка)

## Назначение
Финальная фиксация результатов: генерация отчётов, коммит изменений, документирование.

## Когда использовать
По запросу пользователя, после завершения Харвестера.

## Текущий статус
⏸️ **Временно не используется** — работаем локально, без коммитов и CI.

## Запланированный функционал

### Шаг 1: Генерация отчётов
- Генерация Allure-отчёта
- Создание summary для команды
- Документирование покрытого функционала

### Шаг 2: Коммит изменений
- Формирование commit message
- Добавление @TC-XXXXX аннотаций в тесты
- Создание PR при необходимости

### Шаг 3: Обновление документации
- Обновление coverage matrix
- Документирование новых паттернов
- Обновление README тестов

## Правила
- Активировать только по запросу пользователя
- Все команды git — только с явного разрешения пользователя
